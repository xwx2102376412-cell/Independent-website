## 已确认决策
| 决策 | 实施含义 |
|---|---|
| 美国和欧洲使用同一个商城切换市场与币种 | 数据模型使用统一 Product/Variant，并按市场管理发布与价格；本阶段不新建第二个欧洲站 |
| 暂时保留单管理员 | 现有环境变量登录继续可用，同时增加管理员、角色、权限、会话与审计的数据基础 |
| 先完成后台 US/EU 管理 | Phase 2 支持 USD/EUR 价格和市场发布；商城仍只开放 US，EU 前台进入后续阶段 |
| 保持共享物理库存 | Variant 为物理 SKU，市场价格与发布从 SKU 分离；库存不因 US/EU 重复计算 |

## 实施顺序
1. Phase 1：模块化中文后台、单管理员兼容身份基础、审计日志、通用反馈和导航。
2. Phase 2A：兼容性数据库迁移，新增分类、媒体、参数、选项、市场价格和发布数据。
3. Phase 2B：后台 US/EU 商品编辑与价格发布界面，保留美国商城读取路径。
4. 完整回归：购物车、下单、库存预留、后台和 PayPal 沙盒。
